# Sécurité

Pour signaler une vulnérabilité, **n'ouvrez pas d'issue publique** : écrivez à **support@sport-up.io** avec pour objet `[SECURITY] antd-weekly-calendar`, en indiquant le composant concerné, l'impact et les étapes pour reproduire.

Seule la dernière version de `main` reçoit des correctifs.
